# Plan: Configure App to Use Only PostgreSQL (No SQLite)

## Goal
Make the Django app work exclusively with PostgreSQL - remove SQLite as fallback.

## Current Issue
Local PostgreSQL password `strongpassword` is not set for user `postgres`, causing authentication failure.

## Steps

### 1. Set PostgreSQL password and create database
Run via PostgreSQL CLI or pgAdmin:
```sql
ALTER USER postgres WITH PASSWORD 'strongpassword';
CREATE DATABASE assemblyTravels;
```

### 2. Update .env to use local PostgreSQL
```
DATABASE_URL=postgres://postgres:strongpassword@localhost:5432/assemblyTravels
```
(Remove/comment any SQLite fallback)

### 3. Update settings.py to parse URL
Ensure `get_database_config()` parses the DATABASE_URL correctly.

### 4. Run migrations
```bash
python manage.py migrate
```

### 5. Remove SQLite database file (optional)
Delete `db.sqlite3` to ensure app only uses PostgreSQL.
